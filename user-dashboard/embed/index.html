🌐 My Existing Website

Welcome to Our Product

This demo simulates your already built website. Clicking either referral button will open the popup form powered by the backend.

📋 Code to put on your existing website:

1. Add this button to your HTML:

<button id="referral-btn" class="referral-btn">Refer & Earn 🎁</button>

2. Add the script tag before your closing </body> tag:

<script src="http://localhost:5000/embed.js"></script>
